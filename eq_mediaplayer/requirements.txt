# NotchedMusic — original project requirements

## Project

- Android smartphone app built with Android Studio.
- Test with a virtual device; check whether setup assistance is required.
- Target platform: Google Pixel 10, Android 17.
- Project folder: `Z:\android_projects\NotchedMusic\NotchedMusic-Phone`
- GUI mockups: `Z:\android_projects\NotchedMusic\eq_mediaplayer`

## Purpose

The app is intended for tinnitus retraining through notched music listening. Play music through
Bluetooth headphones.

It includes synchronization over Bluetooth with a smartwatch app that provides the same
functionality but is synchronized by the smartphone app and receives music and filter settings.
The watch cannot provide a generously designed GUI.

The watch app is developed separately; the API between the apps will be expanded later. The first
sync buttons are mockups.

## Music player page

- A root music folder can be selected in the setup menu.
- Root folder and every direct subfolder should be selectable in the player using forward/back
  buttons.
- Titles (files) should then be selectable through title selection using forward/back buttons.
  Deeper subfolders are ignored, producing a flat hierarchy. Files inside the selected folder are
  scanned recursively.
- In practice, the user chooses between the root folder and folders one level below; everything
  inside the selected folder is used recursively.
- Play/stop control.
- Automatic album cover lookup over the internet for supported music files.
- Formats: MP3 and common formats, MP3 prioritised; music only.
- Volume can be controlled by the system or in the app (slider at the bottom).
- EQ bypass (off by default) can bypass all filters when enabled, including filter gain.
- Preset selection dropdown at the bottom right selects the active preset.

## EQ page

- Three presets can be defined, each with six filters (stored locally, transferable to the watch).
- Filters can be selected by clicking: blue outline = selected, green = enabled.
- Filter properties can be selected and edited when a filter is selected.
- Supported filter types: off = filter bypass, notch, bell, high shelf, low shelf, low cut and high
  cut.
- Frequency, Q, gain and volume are entered through edit fields with the keyboard.
- Volume is a kind of trim or preamp gain that should prevent clipping when the signal in the chain
  exceeds 0 dBFS; it can be used to adjust or reduce gain where needed.
- Set the soft limiter correctly so that there is no clipping at the transfer to the operating
  system. Display clipping on the player side near the volume slider.

## Setup page

- "Send to Watch" opens the synchronization page for the smartwatch.
- Root-folder selection is self-explanatory; the app needs access to the music folder, so
  permissions must be checked and requested when starting and while using the app.

## Play sine wave

- To help determine the tinnitus tone, the button should play a sine tone.
- Frequency is adjustable with a slider in roughly 10 Hz steps and with + buttons in 1 Hz steps.
- Volume is adjustable for the test tone.

## Synchronize page

- Root folder and one level of subfolders are listed.
- Selected entries can be transferred to the smartwatch with the "Sync Music" button. The protocol
  follows; the API will be implemented later together with the watch app.
- "Sync EQs" transfers all presets and filter settings to the smartwatch through the API, so the
  watch can provide the same functionality independently without a smartphone: play music with
  filters over Bluetooth.

## Premises

- Performance-optimised DSP algorithms and data structures.
- Stable architecture: many music formats, no Bluetooth playback problems, robust API, automatic
  permission checks.
- The app must work for technology-unsavvy users.
- Tinnitus frequency filter settings are deliberately finely adjustable because accurate tuning is
  important.
